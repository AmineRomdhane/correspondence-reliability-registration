# Data folder

Large raw point clouds, CAD files, ROS bags, and registered point-cloud outputs are not stored directly in this Git repository.

The repository keeps:
- source code,
- configuration files,
- generated CSV tables,
- result figures,
- article files.

To fully reproduce real-data experiments, place the required CAD and scan files in the paths described by the configuration CSV files, or use an external data archive / Git LFS.
